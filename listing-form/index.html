GeoLab Library project listing

Fill out this form to create the listing file for your project. When you're done, open a pull request to add it to the projects/ folder of the geolab-library repository. The library's maintainers are notified when it's opened. See Contributing to the Library for the full steps.

Nothing you enter leaves your browser until you open the pull request yourself.

Fields marked *with an asterisk are required.

File
Letters, numbers, hyphens and underscores. The .yml extension is added for you.
.yml
✕ Enter a file name using only letters, numbers, hyphens and underscores, for example gnss_reflectometry.
About the project
✕ Enter a title for your project.
One or two sentences. This appears on the project's card in the library.
✕ Enter a short summary of your project.
One to four paragraphs on the goals, methods and outcomes of your project. Leave a blank line between paragraphs.
Separate tags with commas, for example seismology, obspy, data_access. Sub-domains, techniques, data types and key packages make good tags.

Difficulty
About how long it takes to work through the project.

Links

Links are checked when you leave each link field. Warnings don't stop you from opening the pull request.

Open pull request opens GitHub with your file already in the projects/ folder. Sign in, choose Commit changes, then Create pull request.
